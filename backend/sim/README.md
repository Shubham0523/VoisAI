# Simulated learners (Day 4)

LLM personas with planted error profiles (e.g. B1, Hindi L1, drops articles, misuses
present perfect) talk to the Friend in text mode for ~20 sessions. Because we know the
planted errors, we can score the Analyst's precision/recall, check that the Planner targets
them, and plot simulated progress. It is the eval suite and the demo data in one.
